# Expo Project Setup Guide

This guide will walk you through the steps to set up and run the existing Expo project on your local machine.

## Prerequisites

- Node.js installed
- Yarn package manager installed

## Steps to Set Up the Project

### 1. Clone the Repository

First, clone the project repository using the following command:

```bash
git clone https://github.com/VoiceNotes-AI/voicenotes-app
```

2. Navigate to the Project Directory
Change into the project directory:

bash
Copy code
cd project
3. Install Dependencies
Install the project dependencies using Yarn:

bash
Copy code
yarn install
4. Run the Project
Now you can run the project using the following command:

bash
Copy code
npx expo
This will start the Expo development server and provide a QR code to open the app in the Expo Go app on your device.
